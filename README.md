## Layout

Erste Design-Ideen in HTML und CSS. Nur statische Beispiele, noch ohne Funktion.

Alles liegt im Ordner `layout`:

- `index.html` - Startseite: Name eingeben, Runde erstellen oder beitreten
- `pokertisch.html` - Pokertisch, die Karten sind noch verdeckt
- `aufgedeckt.html` - Karten sind aufgedeckt, mit Durchschnitt
- `einig.html` - alle haben die gleiche Karte gewählt
- `style.css` - das Aussehen für alle Seiten

Anschauen: `layout/index.html` im Browser öffnen.

Für Codepen (https://codepen.io): HTML ins HTML-Feld kopieren und `style.css` ins CSS-Feld.
